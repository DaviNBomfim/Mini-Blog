# MiniBlog

Uma plataforma de blog desenvolvida com React e Firebase, onde usuários podem compartilhar ideias, publicar conteúdos com imagens e tags, explorar publicações e gerenciar seus próprios posts.

## 📸 Preview


![Página inicial do MiniBlog](../MiniBlog/src/assets/Screenshots/Home.png)

*Página inicial com publicações e pesquisa por tags.*

## ✨ Funcionalidades

- **Autenticação de usuários:** criação de conta e login.
- **Publicação de posts:** criação de publicações com título, imagem por URL, conteúdo e tags.
- **Exploração de conteúdo:** visualização das publicações feitas pelos usuários.
- **Pesquisa por tags:** busca de publicações relacionadas a assuntos específicos.
- **Gerenciamento de posts:** visualização, edição e exclusão das próprias publicações.

## 🛠️ Tecnologias utilizadas

- **React:** construção da interface com componentes reutilizáveis.
- **JavaScript:** implementação da lógica e das funcionalidades da aplicação.
- **Firebase Authentication:** autenticação e gerenciamento de usuários.
- **Cloud Firestore:** armazenamento dos dados das publicações.
- **React Router:** navegação entre as páginas.
- **CSS Modules:** estilização dos componentes com estilos organizados por módulo.

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, pratiquei conceitos importantes para a construção de aplicações web, incluindo:

- Implementação de autenticação com Firebase.
- Criação de hooks personalizados para reutilização de lógica.
- Utilização de Context API para compartilhar o estado de autenticação entre componentes.
- Integração com o Cloud Firestore para criar, consultar, editar e excluir documentos.
- Organização de componentes, páginas e funcionalidades em uma aplicação React.

## 🎯 Objetivo do projeto

O MiniBlog foi desenvolvido com o objetivo de criar uma plataforma de blog simples e funcional, permitindo que usuários compartilhem ideias, pensamentos e experiências.

O projeto também serviu como oportunidade de aprendizado prático em React, autenticação, gerenciamento de estado e integração com banco de dados.
